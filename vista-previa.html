Por qué esto no es un archivo que se abre con doble clic.

Una landing page es un index.html: lo abres y ya. Esto es otra cosa. Hay cuentas de usuario, saldos, comprobantes y compras contra una API externa, y todo eso vive en una base de datos y en un servidor. El navegador solo no puede ejecutarlo: necesita ese servidor encendido.

Opción A — Sin Docker Recomendada

Solo necesitas Node.js. La base de datos va incluida y portátil dentro de la carpeta del proyecto: no requiere virtualización, así que funciona aunque Docker te dé el error «Virtualization support not detected».

  1. Instala Node.js Descarga la versión LTS de nodejs.org y ejecuta el instalador. Siguiente → Siguiente → Instalar.
  2. Descomprime el proyecto Clic derecho sobre recargas-ff.zip → «Extraer todo». Ponlo en un sitio simple como C:\proyectos\, no en Descargas.
  3. Abre una terminal en esa carpeta Windows: clic derecho dentro de la carpeta → «Abrir en Terminal». Mac: clic derecho sobre la carpeta → Servicios → «Nueva terminal en la carpeta».
  4. Escribe estos dos comandos, uno detrás de otro La primera vez tarda unos minutos: descarga las librerías y la base de datos portátil. Después, con npm run demo arranca en segundos. 
    npm install
npm run demo
  5. Abre http://localhost:3000 Regístrate como cliente normal, o entra al panel en /admin:
    usuario admin@demo.local
    contraseña Demo12345

Para apagarlo todo: vuelve a la terminal y pulsa Ctrl + C. Arranca en modo simulado, así que no necesita la API key todavía y no gasta saldo real.

Opción B — Con Docker Necesita virtualización

Un solo comando, si tu equipo puede ejecutar Docker.

docker compose -f docker-compose.dev.yml up

Si Docker Desktop dice «Virtualization support not detected», es la BIOS del equipo, no el proyecto. Puedes ignorarlo y usar la Opción A, o activarlo: reinicia, entra a la BIOS (F2, F10, Supr o Esc al arrancar) y pon en Enabled la opción Intel Virtualization Technology / VT-x (Intel) o SVM Mode / AMD-V (AMD). En equipos de empresa suele estar bloqueada por política. Los pasos completos están en INICIO-RAPIDO.md.
